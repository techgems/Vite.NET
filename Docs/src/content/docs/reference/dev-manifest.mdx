The development manifest, written by the plugin when the Vite dev server starts listening. It tells
the back end how to reach the dev server and mount the app. Consumed by
[`dev-vite-scripts`](/reference/dev-vite-scripts).

## Location

```
wwwroot/{appFolder}/manifest.dev.json
```

For example, `wwwroot/ReactApp/manifest.dev.json`. It is written here (rather than in `dist`) so it
sits alongside where the production build lands.

## When it's written

During the dev server's `listening` event — i.e. once `npm run dev` has started and the server has
bound its port. If you load the hosting page before this happens, the dev tag helper falls back to
its defaults and retries.

## Shape

```json
{
  "port": 5173,
  "entrypoint": "src/main.tsx",
  "containerElementId": "root",
  "isReact": true
}
```

| Field | Type | Description |
| --- | --- | --- |
| `port` | `number` | The port the dev server bound to (`config.server.port`, default `5173`). |
| `entrypoint` | `string` | The entry module passed to `ViteDotNetPlugin`. |
| `containerElementId` | `string` | The mount element id passed to `ViteDotNetPlugin`. |
| `isReact` | `boolean` | Whether a React plugin was detected in the resolved config. |

<Aside type="note">
This maps to the `DevManifestModel` record on the back end:
`record DevManifestModel(int Port, string Entrypoint, string ContainerElementId, bool IsReact)`.
</Aside>
